# Requirements I worked from

I used the current challenge PDF as the source for the project and submission requirements. My implementation follows its Python and LiveKit Agents pipeline requirement, keeps speech recognition, text response generation, and speech synthesis as separate stages, calls only the fixed assessment number, and saves recordings and transcripts.

The submission also needs readable setup instructions, a short architecture explanation, an evidence-based bug report, a private repository, and two Loom videos. The project README and architecture page explain the setup and design; the call index and review notes describe the evidence and its limits.
